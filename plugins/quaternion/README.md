# Proposed `quaternion` plugin

`quaternion` is the planned certified four-component façade over `.cayley`.
This is currently a specification-only package; exact rational quaternion
arithmetic remains available from `.exactAlgebras.Quaternion`.

Phase 1 will add:

- construction from Rationals or certified refinable real singletons;
- named scalar/vector components and basis units;
- parenthesized noncommutative arithmetic;
- conjugation, multiplicative norm, inverse, and explicit left/right division;
- certified component-box refinement and nonzero evidence;
- adapters to exact-algebras without changing its rational schema.

Phase 2 will add intrinsic elementary functions. For `q=a+v`, functions with
real coefficients can use the associative slice generated by `1` and
`v/|v|`, for example

```text
exp(q) = exp(a) (cos(|v|) + v/|v| sin(|v|)).
```

The vector-zero case and logarithm/root branches must remain explicit.
Identities that commute independent quaternion factors are invalid and will
not be imported from ordinary complex algebra.

[`../complex/architecture.md`](../complex/architecture.md), and the phased
checklist in [`../TODO.md`](../TODO.md).

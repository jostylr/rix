# Quaternion plugin

`quaternion` is a four-component typed façade over `.cayley`. Exact Rational
arithmetic stays exact; certified singleton real components retain their
backend identities and refine to enclosing component boxes.

```rix
.Plugin.Load("quaternion");
i := .quaternion.Basis(1);
j := .quaternion.Basis(2);
q := .quaternion.Quaternion(1,2,3,4);
{: (i*j).Components(),(j*i).Components(),q.NormSquared(),q.Inverse() };
```

Division is order-explicit: `x.LeftDivide(d)` means `d⁻¹x`, while
`x.RightDivide(d)` means `xd⁻¹`; `/` uses right division.

`Exp`, `Log`/`LogResult`, `Root`/`RootResult`, `Power`, `Sin`, `Cos`, `Tan`,
`Sinh`, and `Cosh` use the associative slice generated by `1` and the vector
direction. The current elementary kernel is Float-backed and marks records
`approximate=1`; it never presents those values as certified. Exact quaternion
arithmetic and certified component enclosure remain separate. On the negative
real axis, logarithms and roots return an explicit direction-sphere family
unless `branchDirection` is supplied.

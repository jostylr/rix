# Octonion plugin

`octonion` is an eight-component typed façade over `.cayley`. It preserves
written multiplication parentheses, exact composition norms and inverses,
component refinement, and explicit left/right division conventions.

```rix
.Plugin.Load("octonion");
e1 := .octonion.Basis(1);
e2 := .octonion.Basis(2);
e4 := .octonion.Basis(4);
{: ((e1*e2)*e4).Components(),(e1*(e2*e4)).Components(),
   .octonion.VerifyIdentity(:nonassociative,e1,e2,e4) };
```

`VerifyIdentity` supplies exact fixtures for left/right alternativity, a
Moufang identity, and explicit nonassociativity. It never rewrites independent
octonion factors by commutation or reassociation.

`Series(o, coefficients)` evaluates real-coefficient polynomials by a recorded
right-Horner order inside the associative subalgebra generated by `o`.
`Exp`, `Log`/`LogResult`, `Root`/`RootResult`, and `Power` use the same
one-generated slice. Float-backed elementary results are marked approximate;
negative-real roots/logarithms retain their `unitSphere6` direction families.
